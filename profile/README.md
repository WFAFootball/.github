# World Football (WF™)

### Building the future of eFootball.

World Football (WF™) is an open modding platform focused on expanding and modernizing the eFootball experience through advanced technologies, custom game systems, graphical improvements, and community-driven development.

## About

World Football is a complete ecosystem of projects designed to extend the capabilities of eFootball.

Our goal is to provide a modern, modular, and extensible platform where gameplay features, graphical enhancements, tools, and online systems can evolve independently while remaining fully integrated.

---

## Projects

| Project | Description |
|---------|-------------|
| **WF™ 2026** | Main project containing gameplay, UI, career mode, competitions and core game systems. |
| **WF™ Official Graphics** | Official graphical enhancement package including lighting, textures, stadiums, grass and visual improvements. |
| **NoSteamEFB** | Compatibility layer that enables eFootball to run independently from Steam through a custom DLL proxy architecture. |
